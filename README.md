# Configurando-Banco-de-Dados-na-Azure-DIO-
Este resumo aborda o laboratório prático de criação de uma instância de Banco de Dados SQL na Microsoft Azure. No portal do Azure, ao iniciar a criação do banco de dados, preenchem-se os campos necessários conforme a demanda específica do projeto, incluindo a seleção da assinatura e do Grupo de Recursos. Na demonstração, a instrutora utilizou o próprio usuário para resolver um aviso da tela, sem aprofundar na criação de credenciais. O portal exibe o valor estipulado do serviço, e a escolha das configurações deve considerar sempre a demanda e o SLA desejado, garantindo o pagamento adequado pelo nível de serviço e disponibilidade contratados.
